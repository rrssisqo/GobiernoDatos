# Paquete de contexto – Gobierno de Datos

Paquete generado para continuar el proyecto en Claude Code.

1. Descomprime esta carpeta en la raíz de tu repositorio (o crea uno nuevo con ella).
2. Abre Claude Code en esa carpeta: leerá `CLAUDE.md` automáticamente.
3. Usa el prompt de `prompts/01_arranque.md` en la primera sesión.

| Carpeta | Contenido |
|---|---|
| `CLAUDE.md` | Contexto, decisiones y convenciones (lo lee Claude Code en cada sesión) |
| `docs/` | Fuentes y mapeos, modelo y reglas, pantallas, pendientes y backlog, ER v3 (PDF + Mermaid) |
| `db/` | Script SQL Server v2 |
| `mockups/` | 7 pantallas en HTML + PDF |
| `data/muestras/` | Muestras reales: Excel de seguimiento, listas SharePoint, extracto de recertificación |
| `prompts/` | Prompt de arranque |

Nota: `data/muestras/` contiene nombres y usuarios de colaboradores. Si el repositorio
no es privado, anonimízalos antes de subirlo.
